# LeXi 使用指南

Windows 与 macOS 上的轻量桌面词典。输入中英文词语查看释义，输入一段文本进行翻译；在线 AI 补充新词、俚语和专业术语。

## 功能

- 多部离线词典联合查询、简繁检索、词形匹配和输入建议。
- Wiktionary 英语与中文词条作为在线来源，保留原文和来源链接。
- Claude Code / Codex 订阅登录接入，由各自官方程序管理认证。
- Claude Haiku 支持流式显示，释义先出现，例句随后补齐。
- 两个可配置模型同时查词，先返回的结果立即显示；一个模型失败时保留另一个的完整释义。
- 使用 Codex 订阅进行同义项判断，比较同模型和跨模型的释义，合并重复义项与同一用法的细分；独有含义和不确定的区别保留，所有原文均可展开查看。
- 紧凑义项列表保留中文 20、英文 18 的正文大小；例句、来源详情、其他表述和补充说明默认折叠，按需展开，生成与合并过程中保留阅读状态。
- 搜索框右侧状态环在查询中转动、完成后显示勾，未完整完成时显示提示符；悬浮或键盘聚焦查看词典、补充、合并、完成阶段，以及候选数量与稳定状态。
- 单行底栏显示查询状态，提供有边框的“重新生成”按钮，以及有滑块的在线补充开关；长状态可悬浮查看完整内容。
- 音标优先使用离线词典，缺失时补充 Wiktionary IPA；仅由模型提供的音标标注 AI。
- 点击词条旁的扬声器播放合成发音。默认使用 Windows 本地声线，设置中可选 OpenAI/Grok TTS 模型和声线，并试听。
- 中英双向文本翻译，最多 5000 字符，保留大小写、段落与独立缓存。
- 单一多行输入框，自动判断查词、文本翻译与中英方向；文本翻译只使用主要模型。
- 参考 [Raycast 官方界面](https://www.raycast.com/press)的紧凑深色浮窗，统一的结果、来源、设置与键盘操作样式。使用原生 WPF，保留 Lexi 品牌。
- 矢量图标、粉色强调与选中文字高亮、18–20 号释义正文与舒展行距，以及 Windows 11 原生 Acrylic 磨砂背景；文字保持不透明。
- 设置中分别查看离线词典名称、检索条数、大小、版本、来源和许可，并独立启用或停用。
- 不注册全局快捷键。可固定到任务栏第 2 位，使用 Windows 原生 Win+2 切换。

双语释义由模型整理。“来源 · 模型补充”表示现有词典引文不足以核对全部内容，并不表示释义错误。展开来源可查看依据及原始标签；生成中的内容不写入缓存。

## 构建和运行

需要 Windows、PowerShell 7 和 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)。使用 Git 克隆后，在仓库根目录运行：

```powershell
pwsh ./scripts/Build.ps1
pwsh ./scripts/Install-Dictionary.ps1
pwsh ./scripts/Install-ExtendedDictionaries.ps1
./artifacts/Lexi/Lexi.exe
```

构建输出到 `artifacts/Lexi/`。框架依赖版本需要 .NET 10 Desktop Runtime。词库安装脚本下载固定版本的 ECDICT，验证 SHA-256，再生成本地索引；不安装词库也能使用在线查询。

扩展词库来自官方公开下载渠道：

| 词库 | 用途 |
|---|---|
| ECDICT | 英汉释义与词形 |
| Open English WordNet 2025+ | 英英词义与例句，源于 Princeton WordNet 的开放维护版本 |
| 教育部《重編國語辭典修訂本》 | 中文释义，保留繁体原文，支持简体查询 |
| CC-CEDICT | 汉英释义与简繁词条 |
| 国家教育研究院海事术语 | 海事中英专业词汇，包括「车钟」 |
| 国家教育研究院造船工程术语 | 造船与轮机中英专业词汇 |
| [国家教育研究院计算机术语](https://data.gov.tw/dataset/15416) | 计算机与信息技术中英术语 |
| [国家教育研究院计算机两岸译名](https://data.gov.tw/dataset/15275) | 英文、台湾与大陆术语对照，保留各地译名 |
| [国家教育研究院电机工程术语](https://data.gov.tw/dataset/15418) | 电子、电气与通信中英术语 |
| [国家教育研究院物理学术语](https://data.gov.tw/dataset/15317) | 物理学中英术语 |
| [国家教育研究院数学术语](https://data.gov.tw/dataset/15443) | 数学中英术语 |

国家教育研究院词库提供专业术语的中英对应关系，保留原始用词，并增加简体检索索引。完整解释仍由其他词典或单独标注的模型补充提供。两岸对照词库同时索引两地译名；自动繁简转换无法替代“快取 / 缓存”这类用词差异。

已有词库的安装可仅增补指定项，例如：

```powershell
./scripts/Install-ExtendedDictionaries.ps1 -AppDirectory ./artifacts/Lexi -DictionaryIds naer-computer-science,naer-computing-cross-strait,naer-electrical,naer-physics,naer-mathematics
```

安装清单与校验值位于 `dictionaries/catalog.json`。CC-CEDICT 使用滚动官方导出，安装时检查许可并记录当次 SHA-256；其余来源使用固定版本或固定校验值。更新词库前退出 Lexi，完成后重新启动。检索条数包含简繁与同义检索键，不等于互不重复的词义数。旧版本词库保存在数据目录的隐藏备份文件夹中，不参与查询。

要生成带运行时的便携版：

```powershell
pwsh ./scripts/Build.ps1 -SelfContained
```

运行应用后，在“设置”中选择已安装并登录的官方客户端：

- [Claude Code](https://code.claude.com/docs/en/setup)：先完成官方订阅登录，选择 Claude Haiku。
- [Codex](https://learn.chatgpt.com/docs/cli)：先完成 ChatGPT 登录，选择 Luna Fast 或其他可用模型。

模型权限、额度和响应速度取决于服务及账号。Lexi 不附带账号，不收集登录令牌。新安装默认使用 Codex，可在设置中切换至 Claude。

“查询与模型”中可分别选择主要模型、第二个查询模型和义项判断模型。默认启用双模型查词；升级时保留已有主要模型，搭配另一服务的快速模型：主要使用 Codex 时搭配 Claude Haiku，主要使用 Claude 时搭配 GPT-6 Luna。义项判断默认使用 GPT-6 Luna，也可停用合并或双模型查询。两个查询模型不能相同。

义项判断通过本机 Codex CLI 和现有 ChatGPT 登录完成，不调用单独的 Decisions API，也不需要新增 API Key。所有已启用查询模型结束且存在待比较义项时才判断，单模型也会比较内部重复或细分用法；判断期间释义已经可读。同一用法优先展示覆盖更完整的原始解释，其余表述和用法细分可展开核对，各自来源和未核验标记保持独立。不同词性、指代和实质含义保持分开。判断有误的可能仍存在，模型一致不代表事实正确；无法判断、格式无效或超时则保留全部释义。

双模型及后台判断会额外消耗对应订阅额度。完整释义按模型和来源分别缓存，合并结果按全部释义、判断规则版本和判断模型缓存，重复查询无需再次判断。刷新会重新查询和判断。原始离线、在线词典内容保留在可展开的来源区。

## macOS

macOS 版需要 macOS 26 或更新版本，查询、缓存、合并与状态文字与 Windows 版共用同一份 `Lexi.Core`。构建需要 Xcode 26 和 .NET 10 SDK：

```bash
apple/scripts/build-app.sh
open artifacts/macos/LeXi.app
```

用户数据与词库位于 `~/Library/Application Support/LeXi`。安装词库需要 PowerShell 7（例如 `brew install powershell`）：

```bash
pwsh ./scripts/Install-Dictionary.ps1 -AppDirectory "$HOME/Library/Application Support/LeXi"
```

从访达打开的应用拿不到终端的 PATH，LeXi 会另外检查 `~/.local/bin`、Homebrew、`/usr/local/bin`、npm 全局目录和常见 Node 版本管理器来查找 Codex 与 Claude Code；也可在“设置 → 账号连接”中指定 Codex 路径。“登录 / 重新连接”会在“终端”中运行官方登录命令，完成后回到设置点击“检查状态”。

| 按键 | 操作 |
|---|---|
| Return | 查询 |
| Shift-Return 或 Option-Return | 换行 |
| Esc | 收起建议列表 |
| ⌘L | 选中输入框，继续查词 |
| ⌘R | 重新生成 |
| ⌘[ / ⌘] | 后退 / 前进 |
| ⌘Y | 查询历史 |
| ⌘, | 设置 |

关闭窗口不会退出应用，点击 Dock 图标重新打开。发音默认使用系统声线并按文字语言自动选择，也可在“设置 → 发音”中指定系统声线，或选择 OpenAI、Grok 与 ElevenLabs 在线语音。ElevenLabs 账号声线需点击“读取声线列表”。在线语音的 API Key 保存在钥匙串中，不读取环境变量。

## 音标和发音

词条旁以 20 号文字显示音标，与词条共用文字基线，长内容自动换行。优先显示离线词典音标；缺失时独立查询并缓存 Wiktionary 的英语 IPA。悬浮音标可查看来源。仅有模型音标时在旁边显示较小的“AI”标记，悬浮可查看未核验说明；没有可靠音标时留空。

点击扬声器朗读当前输入，再次点击停止。新查询会停止上一条发音。释义、英文释义、例句和例句译文也能朗读：鼠标移到段落上，左侧会浮现扬声器，播放中变为停止按钮，正在朗读的段落以淡金色底标出；也可以在段落上右键选择“朗读”，先选中几个词则只读选中的部分。设置 → 发音提供模型、声线、试听及在线语音连接配置，默认选择 Windows 本地发音，不需要 API Key；可用声线取决于本机安装的 Windows 语音组件。

- [OpenAI TTS](https://developers.openai.com/api/docs/guides/text-to-speech)：支持 GPT-4o mini TTS、TTS-1、TTS-1 HD，声线选项随模型变化。每次最多 4096 字符。
- [Grok TTS](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech)：模型由服务管理，可选 Eve、Ara、Leo、Rex、Sal 声线；应用每次最多朗读 5000 字符。

- [ElevenLabs](https://elevenlabs.io/docs/overview/models)：提供 Flash v2.5、Multilingual v2、Eleven v3、Eleven v4 与 Eleven v4 Turbo。选择模型后，在“在线语音连接”填写 API Key，点击“加载我的声线”，选择账号声线后试听；也可直接用 George 或在“指定其他声线”填写 Voice ID。应用每次最多朗读 5000 字符。

当前 Windows 默认发音使用本机 SAPI，和调用 Edge 在线朗读服务的 `edge-tts` 不同。

在线语音服务使用各自的 API Key，不使用查词的 Codex/Claude 订阅登录。ElevenLabs 的网页生成和 API 使用账号内的共享额度；ElevenReader 是另一套套餐。密钥在“在线语音连接”中填写，保存后通过 Windows 当前用户加密；留空保留已有密钥，勾选清除可删除。也支持 `OPENAI_API_KEY`、`XAI_API_KEY` 或 `ELEVENLABS_API_KEY` 环境变量。自动检查只验证协议和合成响应，真实服务需使用者自己的 API 额度。

发音仅在点击时生成，不会随查询自动播放或切换服务。音频按文字、模型、声线分别缓存；离线模式可使用本地声线和已缓存音频。所有发音均为合成语音。

## 操作

| 按键 | 操作 |
|---|---|
| Enter | 查询 |
| Shift+Enter | 在输入框换行 |
| Esc | 收起建议列表；再次按下则最小化 |
| Ctrl+L | 选中输入框，继续查词 |
| Ctrl+, | 打开设置 |
| Ctrl+Q | 退出应用 |
| 窗口关闭按钮 | 最小化 |

拖动顶部、底栏、结果标题或其他非交互空白区域可移动窗口，拖动边缘可调整大小。输入框、可选文本、按钮与滚动条保留原有操作。输入框下方不显示模式、语言切换或操作说明；Shift+Enter 仍可换行。短句及中英混排自动处理，已收录词语优先查词。

底栏左侧显示查询耗时与处理状态，右侧是“重新生成”按钮和在线补充开关。开关亮起且滑块靠右时允许联网；关闭后只查本地词库与已缓存结果，同时禁用重新生成。词库列表、来源与启停操作集中在设置中，底栏不再显示词库数量。

每个义项以暖色 Serif 斜体突出英文词性，并显示必要的中文用法标签和中英释义。下方的“例句 / 来源 / 其他表述”分别展开对应内容；例句支持选中复制，也可通过 Tab 聚焦入口并用空格展开。生成中状态保留；模型补充提示位于来源入口，展开后可查看说明、模型名称、来源编号与原文链接。新的模型结果到达时保留已打开的内容，新一轮查询恢复折叠。

搜索框右侧的状态环与查询、设置和收起按钮统一尺寸、居中对齐。查询中圆弧转动，完成后变为勾，部分完成或失败时显示提示符；悬浮、点击或键盘聚焦可查看词典、补充、合并、完成四个阶段的完整状态。可以立即阅读候选释义，数量仍可能增减；只有整次处理结束后才提示“已完成”和“结果已稳定”。“稳定”表示本次查询不再自动更新，释义自身的来源与核验标记继续保留。模型或来源失败、合并超时会显示对应的结束状态，并保留可用结果。没有百分比或预计完成时间；关闭系统界面动画时使用静态状态指示。

磨砂背景采用 [Windows 原生 Desktop Acrylic](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type)，需要 Windows 11 build 22621 或更新版本，并启用系统透明效果。不支持的系统、关闭透明效果或高对比度模式下显示深色实底。应用不修改系统偏好。

## 隐私和来源

运行数据位于应用旁的 `userdata/`，包括设置、释义/合并/翻译/音标缓存、音频缓存和加密的语音密钥。分享安装包前应移除这个目录。在线查词会将查询词发送给 Wiktionary，启用 AI 时还会将查询词和许可允许的词典片段发送给所选查询模型服务。启用同义项判断会将查询词和模型释义发送给所选 Codex 判断模型。文本翻译将完整输入发送给主要模型。点击在线发音会将待朗读文字发送给所选语音服务，Windows 发音只使用本机组件。离线模式使用本地词库和已有缓存，不发起新的在线查询。

教育部辞典原文单独显示并保留完整原始字段，不发送给模型改写。模型补充内容与原始词典条目分别标示，来源编号可追溯到具体词典。新版释义使用独立缓存目录，旧的未识别结果不会挡住重新查询。

仓库只包含源码、合成测试数据和维护文件，不包含个人设置、登录数据、查询历史、测速日志、完整词库或第三方客户端。详见 [第三方声明](../THIRD_PARTY_NOTICES.md) 和 [维护约定](../CONTRIBUTING.md)。

## 模型账号连接

设置 → 查询与模型 →“账号登录与连接…”可进入账号页。分别检查 ChatGPT / Codex 与 Claude 的本地登录状态，点击“登录 / 重新连接”后在官方客户端弹出的登录窗口及浏览器内完成 OAuth 授权。授权结束后重新检查状态，再选择模型。

[Codex 官方登录说明](https://learn.chatgpt.com/docs/auth) · [Claude 官方认证命令](https://code.claude.com/docs/en/cli-reference)

LeXi 通过官方状态命令读取登录摘要，不读取凭据文件，也不显示账号标识。登录即时生效，与官方客户端共用账号；取消设置不会撤销授权。状态检查表示本地客户端已有登录配置，实际可用模型仍取决于账号权限。未安装客户端时可从账号页打开官方安装说明；Codex 支持自动检测或手动选择程序。

## 词性与词形

noun、verb 等英文词性以暖色 Serif 斜体突出；常见英文用法标签转换为“书面语”“口语”“俚语”等中文，普通用法不重复标注。模型与资料说明放在可展开的“参考资料”中；原始用法标签仍可查看。

词条下方直接显示 ECDICT 已收录的原形、过去式、过去分词、现在分词、第三人称单数，以及名词复数、形容词比较级和最高级。查询变形词时也会找到原形，例如 tucking → tuck、went → go。词典记录的不同拼写保留并列显示；程序不自行拼接词尾。停用 ECDICT 或关闭离线词库会同时停用这部分离线词形信息。

Windows 与 macOS 的规划见[平台与仓库](architecture.md)。

词形同时读取离线词库和 Wiktionary 的英文词头，覆盖已收录的新词动词变化。在线词形会缓存，离线时继续可用；词库缺少的变化可随模型释义补充。词形用 Serif 正体，与标签共用基线；右键可复制。例句使用 Serif 斜体，中文使用宋体斜体。

模型新增 noun、verb 等用法时，会随同一份回答提供相应词形，一个模型完成即可更新。未完成的词形不显示、不缓存。完整词形可以离线复用；旧版缓存继续可读，并在下次在线查询时更新一次。词典已有的变化优先保留，模型仅补缺项；不同模型意见不同时优先显示主要模型的拼写，其他建议保留在词形悬浮说明中。悬浮也能查看词典或模型来源，模型一致不会被视为词典核验。

## 专业用法、缩写与语源

查询保留大小写，例如 TEE 会先检查缩写并显示英文全称；tee 的普通含义单独保留，词形和音标不会直接混用。加密资产、区块链、密码学、信息安全的已知含义优先展示，附相应领域标签。两模型仍由设置指定，查询不会自动换模型。

应用随附 12 条可离线查看的专业参考摘要，包括 mixer、nonce、TEE、enclave、MPC、MEV、bridge、rollup、oracle、gas、staking、slashing，支持部分全称与中文别名。摘要由 LeXi 编写并链接官方资料，范围有限；更多词汇由词库和模型补充。模型已引用并覆盖的专业摘要收进该义项的“参考资料”，其余摘要作为带出处的释义保留。各条记录见 `Lexi.Core/specialist-references.json`。

语源默认收在词头旁的石碑图标内：可查看 Wiktionary 英文原文，以及模型提供的简短中文说明。词典语源随音标请求读取，可在本次模型请求前已到达时作为参考。原文与模型说明分开展示；资料不确定的历史不应当作定论。语源在浮层中阅读；例句、参考资料和其他表述在义项内展开，均支持键盘操作。

音标统一使用 /…/；异常反斜杠和转义串不显示。优先采用词典音标，模型补充仍有独立标记。升级后相关旧缓存会在联网查询时刷新；大小写不同的条目各自缓存。

### 快速阅读与语源

词头下方的 TL;DR 摘取主要含义，最多展示两条。新生成的速记释义随原有查词请求一同返回；旧缓存和离线词条使用完整短句摘录，不额外调用模型。预览仍可能更新，部分结果表示模型或合并未全部完成，详细用法以完整义项为准。

点击词头旁的石碑图标查看语源浮层；可选择文字、滚动阅读、打开出处，点击外部或按 Esc 关闭。切换查询会清空语源。专业参考摘要收进对应义项的“参考资料”；模型尚未覆盖的专业含义作为带出处的释义保留。

## 查询历史

首页显示最近 30 条主动提交的词条或文本查询，点击一条即可重新查询，右侧 × 可单独删除。清空输入框或点击底栏 ξ 可返回首页。历史从本版本开始记录，只保存在本机 userdata/history.json；删除历史不会删除释义缓存，也不会从缓存重新导入已删除的记录。文本翻译保留完整段落，列表仅显示单行预览。

速览优先显示常用中文译名，按需补一句解释。旧释义缓存可继续离线使用，联网查询时会更新一次以补全译名信息。
