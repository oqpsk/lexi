# LeXi

**查一个词，应该比犹豫要不要查更快。**

读到一半，卡在一个词上。可能是 idempotency，可能是「上岸」，也可能是群聊里突然冒出来的 rizz。要不要查，往往就在一念之间：切窗口、开网页、等加载，三步走完，好奇心已经凉了。

LeXi 是给这一念准备的。在 Windows 或 Mac 上切到它，光标已经在输入框里等着，上次查的词也替你选好了，直接打字，回车。词典先开口，AI 再补上词典还没来得及收的新说法；哪句话是谁说的，都标得明明白白。

## 打字就行，剩下的它来判断

- **一个输入框，什么都能往里放。** 单词、短语、整段文字都行。是查词还是翻译，中译英还是英译中，LeXi 自己判断，不用你先选模式。
- **边打边出候选。** ↑↓ 先看看，Tab 收下，Esc 反悔，回到你原本打的字。
- **整段翻译。** 一次最多 5000 字，段落、大小写、数字和专有名词原样保留。译完一键复制，贴回去就能用。

## 词典打底

AI 懂新词，也懂一本正经地胡说八道。所以 LeXi 永远先翻词典。

- **几部正经词典装在本机，断网照查。** ECDICT 英汉、Open English WordNet 英英、CC-CEDICT 汉英、教育部《重編國語辭典修訂本》，还有国家教育研究院的海事、造船、计算机、两岸计算机译名、电机、物理、数学术语。
- **简体也查得到繁体。** 用简体字照样搜繁体词库；两岸叫法不同的计算机术语（比如「缓存」和「快取」）分别标明台湾与大陆用法，哪种叫法都搜得到。
- **认得变形。** 输入 went，它知道你要的是 go；过去式、分词、复数、比较级排成一行，右键就能复制。
- **联网时再补一层 Wiktionary。** 英文和中文词条、音标、词形、词源一并补上，附原文和链接。
- **原文一直留着。** 每部词典的原始条目都能展开。哪条解释读着别扭，翻出原文对一对。

## 词典来不及收的，交给 AI

- **两个模型一起查。** 谁先答完先看谁；还在生成的释义实时出现，并清楚标明尚未完成。一个模型出了错，另一个照常交卷。
- **说法重复的合并，意思不同的分开。** 两边讲的是同一个义项，就合成一条；真正不同的含义各留各的。被合并的原话也能展开看。
- **先给一句 TL;DR。** 一眼看懂核心意思，想细看再往下读释义、例句和参考资料。
- **新词、黑话、行话都接得住。** 网络流行语，以及加密资产、区块链、密码学、信息安全里的专门义项都有覆盖，领域标签写在旁边。
- **出处说清楚。** 有词典依据的释义附编号链接；模型自己补充的，单独注明；AI 给的音标和词形另做标记，绝不冒充词典。

## 不用再多付一份钱

- **用你已经有的订阅。** LeXi 直接调用电脑上的 ChatGPT（Codex）和 Claude（Claude Code），不需要另买 API 额度。
- **登录交给官方。** 授权在官方客户端里完成，LeXi 不读取、也不保存你的令牌。Mac 上装了 ChatGPT 或 Claude 桌面应用，通常连命令行工具都不用另装。
- **模型自己挑。** 主模型、第二模型、负责合并义项的模型，都能在设置里换。

## 读给你听

- **开箱就能出声。** Windows 用系统自带的语音，macOS 用系统声线，按文字是中文还是英文自动挑。
- **想要更好听，就接在线语音。** OpenAI、Grok、ElevenLabs 任选：挑模型、挑声线、先试听。ElevenLabs 能直接列出你账号里的声线，也能手填 Voice ID。
- **释义和例句也能读。** 鼠标移到释义或例句上，左边会浮出一个小喇叭；右键菜单里也有「朗读」，选中几个词就只读那几个。平时它不占地方，用的时候才出现。
- **钥匙不出门。** API Key 只存在本机：Windows 按当前用户加密，macOS 放进钥匙串。合成过的音频按声线缓存，下次断网也能再听。

## 不让你干等

- **进度看得见。** 输入框旁的状态环告诉你查到了哪一步：词典、补充、合并、完成。它不会编一个百分比，也不会骗你「还剩 3 秒」。
- **查过的不用再等。** 完整结果自动存下，再打开不必联网；觉得旧了，点「重新生成」。
- **随时切到离线。** 一键关掉在线补充，只用本地词库和存过的结果。
- **来回不迷路。** 有查询历史，也能后退、前进，跳回刚才那个词。

## 两个平台，一个大脑

| | Windows | macOS |
|---|---|---|
| 长相 | 原生 WPF，Windows 11 亚克力磨砂背景，常驻托盘 | SwiftUI 与 Liquid Glass，需要 macOS 26 或更新；浅色、深色或跟随系统 |
| 叫出来 | 固定在任务栏第 2 位，Win+2 | Dock 或 ⌘Tab，关掉窗口也不退出 |
| 快捷键 | Enter 查询 · Ctrl+L 回到输入框 · Ctrl+, 设置 · Alt+← / → | Return 查询 · ⌘L 回到输入框 · ⌘, 设置 · ⌘[ / ⌘] · ⌘Y 历史 |
| 安装 | [构建与运行](docs/guide.md) | [从源码构建](apple/README.md) |

两边跑的是同一份查询核心：释义、合并规则、来源说明，连状态栏里的每一句话都一样；界面则各按各的平台规矩来。逐项对照见 [FEATURES.md](FEATURES.md)。

## 数据留在你电脑上

不用注册，不收集使用数据。查询历史、缓存和设置都存在本机；只有查 Wiktionary、调用你选的模型、合成在线语音时才会联网。源码以 MIT 协议开放，词典数据沿用各自的来源与许可。
